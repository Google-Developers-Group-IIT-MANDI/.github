# 🛠️ How We Work

We follow a standard collaborative development workflow.

```bash
# 1. Clone the repository
git clone <repository-url>

# 2. Create your branch
git checkout -b feature/your-feature

# 3. Build something

# 4. Commit
git commit -m "feat: add something awesome"

# 5. Push
git push origin feature/your-feature
```

Then:

```text
OPEN PULL REQUEST
       ↓
CODE REVIEW
       ↓
CHANGES / DISCUSSION
       ↓
APPROVAL
       ↓
MERGE ✅
```

Direct pushes to protected branches should be avoided.

# 🧩 Repository Standards

Active GDG repositories should ideally contain:

```text
README.md
CONTRIBUTING.md
LICENSE
CODE_OF_CONDUCT.md
SECURITY.md
.github/
    ├── ISSUE_TEMPLATE/
    └── PULL_REQUEST_TEMPLATE.md
```

Repositories should also use:

* Issues
* Pull requests
* Code reviews
* Branch protection
* Meaningful commit messages
* Releases where appropriate
